# policy_review
Testing the connection between Claude CLI to JIRA

## Legal document templates
[`templates/`](templates/README.md) contains a dataset of standard legal agreements (Common Paper, CC BY 4.0) that the system will be able to modify for the user, indexed in `templates/catalog.json`.

## Mutual NDA Creator
[`frontend/`](frontend/README.md) is a Next.js prototype that fills in the Common Paper Mutual NDA from a form, shows a live preview and downloads it as a PDF. Run it with `cd frontend && npm install && npm run dev`.
